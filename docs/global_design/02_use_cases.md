# ユースケース定義書

本ブログは認証を持たない公開・読み取り専用のサイトである。そのため、参考リポジトリのような「ログインユーザーによる作成・編集・削除」のユースケースは存在しない。記事の作成・編集・公開は**microCMSの管理画面**で行い、本アプリは配信（閲覧）のみを担う。

## アクター定義

| アクター名 | ID | 説明 | 主な行動 |
|---|---|---|---|
| 読者 | Reader | サイトを訪れる一般の閲覧者。ログイン不要 | 記事を探す・読む、著者情報を見る |
| 商談相手 | Client | ポートフォリオとして本ブログを見る発注検討者。行動は読者と同じ | ブログの内容・実装品質・プロフィールページの経歴を確認する |
| 運営者 | Owner | ブログの著者（本人）。microCMS管理画面で記事を管理する | 記事の入稿・公開（アプリ外の操作） |

> Reader と Client は画面上の操作が同一のため、ユースケース上は Reader にまとめて記述する。区別が必要なのは「プロフィールページ」（UC-PROFILE-View）の設計意図のみ。案件獲得の判断材料になるため、経歴・スキルを読みやすく載せる。

## ユースケース一覧

### 記事の探索

- **UC-ARTICLE-List**（Reader）
  - トップページ（`/`）で最新記事をカード形式で閲覧できる
  - 初期表示は数件。「もっと見る」または記事一覧ページ（`/blogs`）で全件を閲覧できる
  - 公開日の新しい順に並ぶ
- **UC-ARTICLE-FilterByCategory**（Reader）
  - カテゴリタブ（すべて / React / TypeScript ...）で記事を絞り込める
  - タブは記事に紐づくカテゴリから動的に生成される
- **UC-ARTICLE-Search**（Reader）
  - サイドバーの検索ボックスに入力した語で、記事をタイトルの部分一致で絞り込める
  - 本文一致はスコープ外
- **UC-ARTICLE-FilterByMonth**（Reader）
  - ARCHIVE（年月）から、その月に公開された記事へ絞り込める
- **UC-TOPIC-Browse**（Reader）
  - サイドバーの「カテゴリー」（一覧＋件数）を見て、興味のあるカテゴリの記事へ移動できる

### 記事の閲覧

- **UC-ARTICLE-Read**（Reader）
  - 記事カードをクリックして記事詳細ページ（`/blogs/[id]`）を開き、タイトル・公開日・カテゴリ・要約・本文を読める
  - 詳細ページ上部にパンくず（HOME > 記事タイトル）を表示し、トップへ戻れる
- **UC-ARTICLE-ReadOther**（Reader）
  - 詳細ページのサイドバー「ARTICLES（最新の記事）」から、別の記事へ移動できる

### サイト情報

- **UC-ABOUT-View**（Reader）
  - 「このブログについて」（`/about`）でブログのコンセプトを読める
- **UC-PROFILE-View**（Reader / Client）
  - ヘッダーの「プロフィール」または著者カードの「more」から、内部のプロフィールページ（`/profile`）を開ける
  - 著者の自己紹介・経歴・スキルを読める
- **UC-PROFILE-OpenSns**（Reader / Client）
  - 著者カードのSNSアイコン（GitHub / X など）から、外部のSNSを新規タブで開ける
- **UC-NAV-ScrollTop**（Reader）
  - 画面右下の「ページ先頭へ戻る」ボタンで、ページ最上部へ戻れる

### 運営（アプリ外）

- **UC-CMS-Publish**（Owner）
  - microCMS管理画面で記事を入稿・公開すると、本サイトの表示に反映される
  - 本アプリからの書き込み操作は存在しない

## 権限の前提

- すべてのページ・記事は誰でも閲覧できる（認証なし）
- microCMS上で**公開状態**の記事のみが表示対象。下書きはAPIから取得されない
- 本アプリから microCMS へ書き込む操作は行わない（読み取り専用のAPIキーで足りる）

## 検索・絞り込み仕様

| 項目 | 仕様（MVP） |
|---|---|
| キーワード検索 | 記事タイトルの部分一致（大文字小文字は区別しない） |
| カテゴリ絞り込み | 選択したカテゴリを1つ以上持つ記事。同時に選べるのは1カテゴリ |
| 月絞り込み | 公開日（`publishedAt`）が指定年月に含まれる記事 |
| 条件の組み合わせ | キーワード・カテゴリ・月はAND条件で組み合わせられる |
| 並び順 | 公開日の降順（新しい順）固定 |
| 該当なし | 「該当する記事がありません」を表示する |

## 例外・エッジケース

| ケース | 期待する挙動 |
|---|---|
| 存在しない記事ID（`/blogs/xxx`）にアクセス | 404ページ（`notFound()`）を表示する |
| microCMSへの接続に失敗 | エラー境界（`error.tsx`）でエラー表示。ビルド時は失敗として検知する |
| 記事が0件 | 一覧に空状態メッセージを表示し、カテゴリタブは「すべて」のみ |
| カテゴリが未設定の記事 | カテゴリタグなしで表示。TOPICSの集計対象外 |
| 画像（アイキャッチ）が未設定 | カテゴリから導出したカード装飾（`card`）で生成するサムネイルで代替する |
