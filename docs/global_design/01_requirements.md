# 要件定義書

## 背景

- 個人の技術学習のアウトプットを残す場として、また案件獲得時の商談で提示するポートフォリオとしても機能する技術ブログを構築する。
- デザインは「MARGIN | TECH JOURNAL」というモックとして作成済みで、本ドキュメントはこのモックを実装するための設計をまとめたもの。

## 目的

- モックで示されたデザイン・機能をNext.js（App Router）+ microCMSで実装する。
- [immortal-architecture-mvp](https://github.com/YukiOnishi1129/immortal-architecture-mvp)、[Next.js App Router アーキテクチャの設計思想](https://zenn.dev/yukionishi/articles/cd79e39ea6c172) を参考に、意図の伝わる層構造を持つコードベースにし、技術力のアピール材料にする。

## 機能要件

### 共通レイアウト

- ヘッダー: ロゴ（MARGIN / TECH JOURNAL）、ナビゲーション（記事一覧・このブログについて・プロフィール[外部リンク]）
- フッター: ロゴ、コピーライト、ページ先頭へ戻るリンク

### トップページ（`/`）

- ヒーローセクション: キャッチコピー、タイトル、サブタイトル、付随情報（PERSONAL TECH BLOG / EST. 2026 — VOL.01）
- 最新記事セクション
  - 記事件数表示（◯◯ ARTICLES）
  - カテゴリフィルタタブ（すべて / React / TypeScript / CSS / Testing / Git など、記事に紐づくカテゴリから動的に生成）
  - 記事カード一覧（下記「記事カード」参照）
- サイドバー
  - 記事検索ボックス
  - 著者情報カード（アバター、名前、肩書き、自己紹介、プロフィールページへのリンク）
  - カテゴリ一覧（TOPICS、カテゴリごとの記事数）
  - アーカイブ（年月ごとの記事数）
  - 一言メッセージ枠（引用的なコピー）

### 記事カード

- サムネイル（大きな装飾文字＋小さなキャプション文字、記事ごとに配色バリエーション）
- 投稿日、想定読了時間、NEWバッジ（新着記事のみ）
- タイトル、要約文
- カテゴリタグ（複数可）

### 記事一覧ページ（`/blogs`）

- トップページと同じ記事カードを使った全件一覧（フィルタ・検索に対応）

### 記事詳細ページ（`/blogs/[id]`）

- タイトル、投稿日、本文（microCMSのリッチエディタ由来のHTML）

### このブログについてページ（`/about`、新規）

- ブログのコンセプト説明

### プロフィール

- 外部サイトへのリンク（実装対象外、遷移先URLのみ設定）

## 非機能要件

- コンテンツソースはmicroCMSのみとする。Qiitaからの記事取得は当初予定していたが、**スコープ外とする**（既存の`app/api/qiita/route.ts`等は撤去対象。詳細は[frontend/05_development_guide.md](../../frontend/docs/05_development_guide.md)参照）。
- 認証機能は持たない（読み取り専用の公開ブログ）。
- 独自DBは持たない（microCMSをデータソースとする）。
- レスポンシブ対応（PC・タブレット・スマートフォン）。
- SEOを意識したメタデータ（Next.jsの`generateMetadata`）を各ページに設定する。
- デプロイはVercel想定（現行構成から変更なし）。

## スコープ外（将来検討）

- コメント・リアクション機能
- 検索の本文一致対応（現時点ではタイトル・カテゴリの絞り込みを想定）
- 多言語対応
