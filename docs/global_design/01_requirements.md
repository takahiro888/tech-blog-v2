# 要件定義書

## 背景

- 個人の技術学習のアウトプットを残す場として、また案件獲得時の商談で提示するポートフォリオとしても機能する技術ブログを構築する。
- デザインは「MARGIN | TECH JOURNAL」というモックとして作成済みで、本ドキュメントはこのモックを実装するための設計をまとめたもの。

## 目的

- モックで示されたデザイン・機能をNext.js（App Router）+ microCMSで実装する。
- [immortal-architecture-mvp](https://github.com/YukiOnishi1129/immortal-architecture-mvp)、[Next.js App Router アーキテクチャの設計思想](https://zenn.dev/yukionishi/articles/cd79e39ea6c172) を参考に、意図の伝わる層構造を持つコードベースにし、技術力のアピール材料にする。

## 機能要件

### 共通レイアウト

- ヘッダー: ロゴ（MARGIN / 技術ブログ）、ナビゲーション（記事一覧・このブログについて・プロフィール。いずれも内部リンク）、キャッチコピー（`つくって、試して、わかったこと。Web開発の学びをここに。`）。キャッチコピーはページによらず全ページ共通でヘッダーの一部として常時表示する
- フッター: ロゴ、コピーライト、ページ先頭へ戻るリンク

### トップページ（`/`）… 記事一覧を兼ねる

> 旧案にあった「記事一覧ページ（`/blogs`）」は廃止し、トップページに統合する。トップページの「最新記事セクション」が全記事のページネーション一覧を兼ねるため、別ページへの遷移なしに全件へアクセスできる（詳細は[04_ui_design.md](./04_ui_design.md)参照）。

- ヘッダー直下のパンくず: カテゴリ・月の絞り込み時のみ`HOME > カテゴリ名`または`HOME > YYYY年M月`を表示する（絞り込みなし時は非表示）。旧案にあった大見出し「技術と、日々の余白。」は廃止した（詳細は[04_ui_design.md](./04_ui_design.md)参照）
- 最新記事セクション
  - 見出し: 絞り込みなし時は見出しテキストを表示しない。カテゴリ・月で絞り込んだときのみ`「◯◯」の記事一覧` / `◯年◯月の記事一覧`を表示する
  - カテゴリ絞り込み: 一覧上部のタブは持たず、サイドバーの「カテゴリー」一覧から行う（月の絞り込みと同じ構造）
  - 記事カード一覧（下記「記事カード」参照）。フィルタ・検索後の該当記事を対象に、ページ単位で表示する
  - 件数表示（「◯件中 ◯〜◯件を表示」）
  - 表示件数セレクト（10 / 20 / 30件など。既定10件）
  - ページネーション（前へ・ページ番号・次へ）
- サイドバー
  - 記事検索ボックス
  - 著者情報カード（アバター、名前、肩書き、自己紹介、内部プロフィールページ`/profile`へのリンク）
  - カテゴリ一覧（「カテゴリー」、カテゴリごとの記事数）
  - アーカイブ（年月ごとの記事数）
  - 一言メッセージ枠（引用的なコピー）

### 記事カード

- サムネイル（大きな装飾文字＋小さなキャプション文字、記事ごとに配色バリエーション）
- 投稿日、「新着」バッジ（新着記事のみ）
- タイトル、要約文
- カテゴリタグ（複数可）

### 記事詳細ページ（`/blogs/[id]`）

- パンくず（HOME > 記事タイトル）、タイトル、投稿日、本文（microCMSのリッチエディタ由来のHTML）

### このブログについてページ（`/about`、新規）

- ブログのコンセプト説明

### プロフィールページ（`/profile`、新規）

- 著者の自己紹介を掲載する内部ページ（外部サイトへは遷移しない）
- パンくず（HOME > プロフィール）、ページタイトル、メインビジュアル画像、本文（自己紹介・経歴・スキルなど。見出しを含む長めの文章）
- サイドバー（検索・著者カード・カテゴリ・アーカイブ）は他ページと共通
- 著者カードのSNSアイコン（GitHub / X など）は外部リンクとして持つ
- 内容はmicroCMSの`profile`（オブジェクト形式）で管理する

## 非機能要件

- コンテンツソースはmicroCMSのみとする。Qiitaからの記事取得は当初予定していたが、**スコープ外とする**（既存の`app/api/qiita/route.ts`等は撤去対象。詳細は[frontend/05_development_guide.md](../../frontend/docs/05_development_guide.md)参照）。
- 認証機能は持たない（読み取り専用の公開ブログ）。
- 独自DBは持たない（microCMSをデータソースとする）。
- レスポンシブ対応（PC・タブレット・スマートフォン）。
- SEOを意識したメタデータ（Next.jsの`generateMetadata`）を各ページに設定する。
- デプロイはVercel想定（現行構成から変更なし）。

## スコープ外（将来検討）

- コメント・リアクション機能
- 検索の本文一致対応（現時点ではタイトル・カテゴリの絞り込みを想定）
- 多言語対応
