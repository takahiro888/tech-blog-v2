# UI設計書

「MARGIN | TECH JOURNAL」のモック（トップ／記事一覧、記事詳細）に基づく画面設計。参考リポジトリの`04_ui_design.md`に相当する。

> 寸法・色は、モックのスクリーンショットから読み取った**目安値**。実装時にモック本体（[margin-tech-notes](https://margin-tech-notes.hondatakahiro371.chatgpt.site/)）と見比べて調整すること。

## 1. 画面一覧

| 画面 | パス | 概要 | モック |
|---|---|---|---|
| トップページ | `/` | ヒーロー＋最新記事（フィルタ）＋サイドバー | 画像① |
| 記事一覧 | `/blogs` | 全記事一覧。トップと同じ構成でヒーローなし | 画像①を流用 |
| 記事詳細 | `/blogs/[id]` | 記事本文＋サイドバー | 画像② |
| このブログについて | `/about` | コンセプトの静的ページ（新規） | なし（要デザイン） |
| プロフィール | `/profile` | 著者の自己紹介ページ（新規）。パンくず＋タイトル＋メイン画像＋本文＋サイドバー | 参考画像（別ブログの例） |
| 404 | （自動） | 記事が存在しない場合 | なし |

## 3. 共通レイアウト

### 3.1 グリッド

| 項目 | 仕様（目安） |
|---|---|
| コンテンツ最大幅 | 約1200px、中央寄せ |
| 2カラム | メイン約876px ／ サイドバー約270px ／ 間隔約68px |
| ヘッダー高さ | 約96px。下端に1pxの罫線 |
| 余白 | 左右のガター（モバイルは16px） |

### 3.2 ヘッダー

```
┌────────────────────────────────────────────────────────────────────┐
│ [m.] MARGIN │ TECH JOURNAL            記事一覧  このブログについて  プロフィール │
└────────────────────────────────────────────────────────────────────┘
                                        ▔▔▔▔▔  ← 現在ページに青い下線
```

- ロゴ: 青い角丸の正方形に白い「m.」＋「MARGIN」（大文字・字間広め・太字）＋縦線＋「TECH JOURNAL」（小さく・字間広め・グレー）
- ナビ: 「記事一覧」「このブログについて」「プロフィール」はすべて内部リンク（`/`系は「記事一覧」、`/about`、`/profile`）。モックの「プロフィール ↗」は外部リンク表記だったが、内部ページ化に伴い↗アイコンは外す
- **アクティブ表示**: 現在のパスに対応する項目を青文字＋ヘッダー下端に太さ2px程度の青いアンダーライン。`/`と`/blogs`と`/blogs/[id]`はいずれも「記事一覧」をアクティブとする
- 記事詳細ページでは、ヘッダー最上部に紺色の細いライン（約5px）が付く

### 3.3 フッター

- ロゴ、コピーライト、ページ先頭へ戻るリンク

### 3.4 ページ先頭へ戻るボタン（ScrollTop）

- 右下固定の円形ボタン（上向きシェブロン）。一定量スクロールしたら表示する
- クリックでページ最上部へスムーズスクロール。`aria-label="ページの先頭へ戻る"`

## 4. カラー・タイポグラフィ（目安）

| 役割 | 値の目安 | 用途 |
|---|---|---|
| Primary（青） | `#1D4ED8`前後 | アクティブナビ、アイキャッチ文字、リンク、NEWバッジ文字 |
| Navy（紺） | `#1E293B`〜`#172554` | 選択中フィルタ、`dark`テーマのサムネイル、ヘッダー上端ライン |
| Text | `#1F2937`前後 | 見出し・本文 |
| Muted（グレー） | `#6B7280`〜`#9CA3AF` | 要約文、メタ情報、ラベル |
| Border | `#E5E7EB`前後 | 罫線・カード枠・検索ボックス枠 |
| Surface | `#F3F4F6`前後 | カテゴリタグ背景、検索ボックス背景、パンくず背景（青みがかったグレー） |

- 日本語見出しは太字の大きなサイズ（ヒーロー約36px、記事タイトル約32px、カードタイトル約18px）
- 英字ラベル（`CODE, LEARN, LEAVE A NOTE.` / `THE AUTHOR` / `TOPICS` など）は**大文字・小さめ・字間広め（letter-spacing）**で統一する。青いものと黒いものがある
- 等幅フォントをサムネイルのキャプションに使う（`type Safe = Learn<T>`）
- フォントは`next/font`で読み込む（欧文はInter系、和文はNoto Sans JP系を想定。要確認）

## 5. トップページ（`/`）

```
┌ ヘッダー ─────────────────────────────────────────────────────┐
│ ヒーロー                                                          │
│  CODE, LEARN, LEAVE A NOTE.                PERSONAL TECH BLOG     │
│  技術と、日々の余白。                       EST. 2026 — VOL. 01    │
│  つくって、試して、わかったこと。…                                │
│ ─────────────────────────────────────────────────────────────── │
│ Latest articles 最新の記事                       06 ARTICLES  │ [🔍 記事を検索] │
│ [すべて][React][TypeScript][CSS][Testing][Git]   │ ┌THE AUTHOR──┐ │
│ ┌────────┐ 2026.09.14 — 3 min read [NEW]         │ │ (m_)        │ │
│ │サムネ  │ 記事タイトル                          │ │ ある Web…   │ │
│ └────────┘ 要約  [TypeScript]                    │ └プロフィールを読む→┘ │
│ ────────────────────────────────────────────    │ TOPICS カテゴリー │
│ ┌────────┐ …                                     │ React        1  │
│ [もっと見る]                                     │ TypeScript   3  │
└──────────────────────────────────────────────────┴───────────────┘
```

### 5.1 ヒーロー

| 要素 | 内容 | 管理方法 |
|---|---|---|
| アイキャッチ文言 | `CODE, LEARN, LEAVE A NOTE.`（青・小さい英字ラベル） | 定数 |
| タイトル | `技術と、日々の余白。`（大見出し／ページのh1） | 定数 |
| サブタイトル | `つくって、試して、わかったこと。Web開発の学びをここに。` | 定数 |
| 付随情報（右寄せ） | `PERSONAL TECH BLOG` / `EST. 2026 — VOL. 01` | 定数 |

- 変更頻度が低いため、`shared/lib/constants.ts`に定数として持つ（microCMSでは管理しない）。**`/blogs`ではヒーローを表示しない**（見出しのみのコンパクトなヘッダー）

### 5.2 最新記事セクション

| 要素 | 仕様 |
|---|---|
| 見出し | `Latest articles`（太字・英字）＋`最新の記事`（小さなグレーの日本語） |
| 件数 | 右端に`06 ARTICLES`。**現在の絞り込み結果の件数**を2桁ゼロ埋めで表示 |
| カテゴリフィルタ | 「すべて」＋記事に紐づくカテゴリ。選択中は紺の塗り＋白文字、未選択は白地に枠線。1つだけ選択可 |
| 記事カード一覧 | 縦積み。カード間は罫線で区切る |
| 「もっと見る」 | トップでは初期6件表示。超過分がある場合のみボタン表示（[04_data_fetching_policy.md](../../frontend/docs/04_data_fetching_policy.md)の方針どおり） |
| 空状態 | 「該当する記事がありません」 |

### 5.3 記事カード（ArticleCard）

```
┌──────────┐  2026.09.14 ─ 3 min read [NEW]
│MARGIN/TECH NOTE│  TypeScriptの型を、もう一歩使いこなす。
│ TypeScript │  ユニオン型と型ガードで、安全で読みやすいコードに。
│type Safe=…│  [TypeScript]
└──────────┘
```

| 要素 | 仕様 |
|---|---|
| サムネイル | 約260×160。左上に`MARGIN / TECH NOTE`（固定・小さな等幅）、中央に`cardLabel`（大きな太字）、左下に`cardCaption`（等幅）、背景に装飾の図形。配色は`cardTheme`で切り替え（`blue`は淡い青地に青文字、`dark`は紺地に白文字、他は`green`/`purple`/`black`） |
| メタ行 | `YYYY.MM.DD` ─ `N min read` ＋ NEWバッジ（新着のみ） |
| タイトル | 太字。カード全体がリンク（`/blogs/[id]`）。キーボードフォーカス可能 |
| 要約 | グレー、1〜2行で省略 |
| カテゴリタグ | 薄いグレー背景の小さなラベルを横並び。複数可 |
| ホバー | タイトルの色変化またはカードの軽い浮き上がり（過度な演出は避ける） |

- NEWバッジの条件は[05_domain_design.md](./05_domain_design.md)の`isNew`を参照
- `eyecatch`画像がある場合の扱い: MVPでは**サムネイルは常に装飾表現**とし、画像は詳細ページ側で使う余地として残す（要判断）

### 5.4 サイドバー

| ブロック | 内容 |
|---|---|
| 検索ボックス | 虫眼鏡アイコン付き、プレースホルダー`記事を検索`。入力に応じてタイトル部分一致で一覧を絞り込む（[UC-ARTICLE-Search](./02_use_cases.md)） |
| 著者カード | `THE AUTHOR`ラベル、円形アバター（`m_`）、名前（`ある Web エンジニア`）、肩書き（`FRONTEND DEVELOPER`）、自己紹介3行、罫線、`プロフィールを読む`（内部リンク→`/profile`）。SNSアイコン（GitHub / X など）は外部リンクとして新規タブで開く |
| TOPICS | 見出し`TOPICS`＋`カテゴリー`。カテゴリ名と件数（小さなグレーのバッジ）を罫線区切りで縦並び。クリックでそのカテゴリに絞り込む |
| ARCHIVE | `YYYY年MM月`と件数。クリックでその月に絞り込む（[01_requirements.md](./01_requirements.md)） |
| メッセージ枠 | 一言コピー（静的） |

- 記事詳細ページでは、TOPICSの下に**ARTICLES（最新の記事）**を出す（後述）

## 6. 記事一覧ページ（`/blogs`）

- トップの「最新記事セクション」＋サイドバーと同一構成（ヒーローなし）
- すべての記事を表示（「もっと見る」なし）
- URLパラメータ: `?category=<slug>` `?q=<keyword>` `?month=<YYYY-MM>` を初期状態として受け付ける（トップの`TOPICS`/`ARCHIVE`からの遷移用）
- 絞り込みはMVPではクライアント側で行う（案A）。記事が増えたらサーバー側（案B）へ移行する

## 7. 記事詳細ページ（`/blogs/[id]`）

```
┌ ヘッダー（上端に紺ライン） ───────────────────────────────────┐
│ HOME ＞ TypeScriptの型を、もう一歩使いこなす。   ← パンくず帯（青みグレー背景）│
│ ┌─────────────────────────────┐ │ [🔍 記事を検索]    │
│ │  大きなサムネイル（16:9）     │ │ THE AUTHOR …       │
│ └─────────────────────────────┘ │ TOPICS …           │
│ 2026.09.14 ─ SAMPLE ARTICLE      │ ARTICLES 最新の記事 │
│ TypeScriptの型を、もう一歩使いこなす。│  ・…               │
│ [TypeScript]                     │                    │
│ ユニオン型と型ガードで、…(要約)  │                    │
│ ───────────────────────────      │                    │
│ 本文…                            │                    │
└──────────────────────────────────┴────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| パンくず | 全幅の帯。`HOME`（青・リンク→`/`）＞ 記事タイトル（グレー・現在地） |
| ヒーローサムネイル | 記事カードと同じ装飾サムネイルを大きく表示（角丸、約876×490） |
| メタ行 | `YYYY.MM.DD` ─ ラベル。ラベルはモックでは`SAMPLE ARTICLE`。本番では`ARTICLE`固定、またはカテゴリ名を出す（要判断） |
| タイトル | h1。太字・大きめ |
| カテゴリタグ | カードと同じ表現 |
| 要約 | グレーの大きめ本文 |
| 罫線 | 要約と本文の区切り |
| 本文 | microCMSのリッチエディタHTML。見出し・段落・リスト・コード・画像・引用にスタイルを当てる（`prose`相当のスタイルを用意）。HTMLは信頼できる自前CMS由来だが、描画前にサニタイズする（[07_api_design.md](./07_api_design.md)参照） |
| サイドバー | 検索・著者・TOPICSに加え、**ARTICLES（最新の記事）**を数件表示。表示中の記事自身は除く |

- 前後の記事へのリンク、シェアボタン、関連記事は**MVP対象外**

## 8. このブログについて（`/about`）

- 見出し、コンセプト文、プロフィールページ（`/profile`）へのリンク。デザインは他ページのトーンに合わせる
- 文章は定数または`page.tsx`内に直接記述（CMS管理しない）

## 8-2. プロフィールページ（`/profile`）

別ブログの参考画像（パンくず＋タイトル＋メイン画像＋本文＋右サイドバー）の**構成**を取り入れ、見た目は本ブログ（MARGIN）のトーンで作る。参考画像の配色・枠線・ボタン形状はそのまま真似ない。

```
┌ ヘッダー（「プロフィール」がアクティブ） ────────────────────┐
│ HOME ＞ プロフィール                      ← パンくず帯（詳細ページと同じ）│
│ プロフィール                      │ [🔍 記事を検索]          │
│ ─────────────────────────      │ THE AUTHOR（著者カード）  │
│ ┌────────────────────────┐    │ TOPICS                   │
│ │ メインビジュアル画像      │    │ ARCHIVE                  │
│ └────────────────────────┘    │                          │
│ 本文（見出し＋段落＋リスト）      │                          │
└─────────────────────────────────┴──────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| パンくず | `HOME`（リンク→`/`）＞ `プロフィール`。詳細ページと同じ部品を再利用する |
| ページタイトル | h1「プロフィール」＋下に罫線 |
| メイン画像 | 任意。角丸、横長（16:9または3:2）。未設定なら非表示 |
| 本文 | microCMSのリッチエディタHTML。「何をしている人か」「経歴」「スキル」などの見出し（h2）で区切る。h2は左に青いアクセントラインなど、MARGINのトーンで装飾する。記事詳細の本文スタイルを共用する |
| サイドバー | 検索・著者カード・TOPICS・ARCHIVE。**プロフィールページ上の著者カードは重複するため非表示にする案**もある（要判断） |
| シェアボタン | 参考画像にはあるが、**MVP対象外**（記事詳細のシェアと同じ扱い） |
| SNSアイコン | 著者カード内に表示（本文内には置かない） |

- 商談での提示先になるため、**経歴・使用技術・得意領域・連絡方法**を本文に載せる（掲載内容は運営者が決める）
- SEO: `generateMetadata`で`title`=「プロフィール」、`description`=著者の`bio`

## 9. レスポンシブ

| 幅 | レイアウト |
|---|---|
| PC（1024px以上） | 2カラム（メイン＋サイドバー） |
| タブレット（〜1023px） | 1カラム。サイドバーはメインの下に移動 |
| スマホ（〜639px） | 1カラム。記事カードはサムネイルを上、テキストを下に縦積み。ナビはコンパクト表示（ハンバーガー、または折り返し）。フィルタタブは横スクロール可 |

- ヘッダーのナビがスマホで収まらない場合の表示方法（ハンバーガー／折り返し）は実装時に決める

## 10. アクセシビリティ・SEO

- ナビは`<nav aria-label>`、現在ページに`aria-current="page"`
- カードのリンクはタイトルにアンカーを置き、カード全体をクリック可能にしても読み上げが重複しないようにする
- 装飾サムネイルは`aria-hidden`（情報はタイトル側にあるため）
- 色だけに頼らない（選択中フィルタは背景色＋`aria-pressed`）
- ページごとに`generateMetadata`で`title` / `description`（要約を利用）/ OGP を設定する
- 見出しは各ページでh1を1つにする（トップは「技術と、日々の余白。」、詳細は記事タイトル）
