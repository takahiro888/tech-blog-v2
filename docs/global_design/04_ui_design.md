# UI設計書

「MARGIN | TECH JOURNAL」のモック（トップ／記事一覧、記事詳細）に基づく画面設計。参考リポジトリの`04_ui_design.md`に相当する。

> 寸法・色は、モックのスクリーンショットから読み取った**目安値**。実装時にモック本体（[margin-tech-notes](https://margin-tech-notes.hondatakahiro371.chatgpt.site/)）と見比べて調整すること。

## 1. 画面一覧

> 旧案の「記事一覧（`/blogs`）」は廃止し、トップページに統合した。トップページの最新記事セクションが、フィルタ・検索・ページネーションを備えた全記事一覧を兼ねる。

| 画面 | パス | 概要 | モック |
|---|---|---|---|
| トップページ（記事一覧を兼ねる） | `/` | ヘッダー（キャッチコピー行を含む）＋（絞り込み時のみ）パンくず＋最新記事（フィルタ・検索・ページネーション）＋サイドバー | 画像①（絞り込みなし）／画像③④（カテゴリ・月絞り込み時のパンくず・見出し切り替え）。ページネーション部は別途共有されたモック画面を参照 |
| 記事詳細 | `/blogs/[id]` | パンくず＋記事本文＋サイドバー | 画像② |
| このブログについて | `/about` | コンセプトの静的ページ（新規） | なし（要デザイン） |
| プロフィール | `/profile` | パンくず＋タイトル＋メイン画像＋本文＋サイドバー | 画像⑤（パンくず）／参考画像（別ブログの例。本文構成のみ） |
| 404 | （自動） | 記事が存在しない場合 | なし |

```
       │
       └─ サイドバー ─ TOPICS / ARCHIVE ──▶ [/ 絞り込み済み（searchParams付き）]
```

### 3.2 ヘッダー

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 紺の上端ライン（全ページ共通）
 [m.] MARGIN │ 技術ブログ              記事一覧  このブログについて  プロフィール
                                        ▔▔▔▔▔  ← 現在ページに青い下線（ナビ行の下端）
 ────────────────────────────────────────────────────────────────
 つくって、試して、わかったこと。Web開発の学びをここに。        ← キャッチコピー行
────────────────────────────────────────────────────────────────────
```

- ロゴ: 青い角丸の正方形に白い「m.」＋「MARGIN」（大文字・字間広め・太字）＋縦線＋「技術ブログ」（小さく・グレー）
- ナビ: 「記事一覧」「このブログについて」「プロフィール」はすべて内部リンク（`/`系は「記事一覧」、`/about`、`/profile`）。モックの「プロフィール ↗」は外部リンク表記だったが、内部ページ化に伴い↗アイコンは外す
- **アクティブ表示**: 現在のパスに対応する項目を青文字＋ナビ行の下端に太さ2px程度の青いアンダーライン（キャッチコピー行がヘッダー下部にあるため、下線はナビ行の下端に付ける）。`/`と`/blogs/[id]`はいずれも「記事一覧」をアクティブとする。現在のパスの判定にはClient Componentの`usePathname`が必要なため、リンク部分のみ`NavLink`として切り出し、ヘッダー本体はServer Componentのままにする
- ヘッダー最上部に紺色の細いライン（約5px）が付く。モック（トップページ）でも確認できたため、記事詳細だけでなく全ページ共通とする
- **キャッチコピー行**: ロゴ・ナビの行の直下に、`つくって、試して、わかったこと。Web開発の学びをここに。`を1行で表示する。ページによる出し分けはなく、**全ページ共通でヘッダーの一部として常時表示**する（旧案では絞り込みなし時のトップページだけに出す案だったが、モックに合わせてヘッダー自体の一部に変更した）
- キャッチコピー文言は変更頻度が低いため、`shared/lib/constants.ts`に定数として持つ（`CATCH_COPY`）

### 3.3 ヘッダー直下のパンくず

トップページの絞り込み時・記事詳細・プロフィールでは、ヘッダー（キャッチコピー行を含む）のすぐ下にパンくずの帯が入る。それ以外（トップページの絞り込みなし時）は何も入らず、本文がそのまま続く。

| 状態 | 表示内容 | 対象ページ |
|---|---|---|
| パンくず帯 | `HOME`（青・リンク→`/`）＞ 現在地（グレー） | トップページの絞り込み時（画像③④）、記事詳細（画像②）、プロフィール（画像⑤） |
| なし | ヘッダーの直後に本文（最新記事セクション）が続く | トップページの絞り込みなし時（画像①） |

- 旧案にあった大見出し「技術と、日々の余白。」は廃止した。トップページのh1は、絞り込み時のみ最新記事セクションの見出しが兼ねる（[5.1](#51-パンくずと見出しの切り替え)参照）
- パンくずの部品は共通化し、トップページの絞り込み時・記事詳細・プロフィールで再利用する（[11章](#11-コンポーネント対応表)参照）

### 5.1 パンくずと見出しの切り替え

トップページのヘッダー直下は、絞り込み状態によって表示が変わる（[3.3](#33-ヘッダー直下のパンくず)参照）。キャッチコピーはヘッダーの一部として全ページ共通で常時表示するため、ここでの出し分け対象ではない。旧案にあった大見出し「技術と、日々の余白。」、および最新記事セクションの固定見出し「最新の記事」はいずれも廃止した（ページネーションで後方のページを見ているときに「最新」と表示するのが実態に合わないため）。

| 状態 | ヘッダー直下のパンくず | 最新記事セクションの見出し（h1） | 該当画像 |
|---|---|---|---|
| 絞り込みなし（初期表示） | なし（ヘッダーの直後に本文が続く） | なし（見出しテキストは表示しない） | 画像① |
| カテゴリ絞り込み中 | `HOME ＞ {カテゴリ名}` | `「{カテゴリ名}」の記事一覧` | 画像③ |
| 月（アーカイブ）絞り込み中 | `HOME ＞ {YYYY年M月}` | `{YYYY年M月}の記事一覧` | 画像④ |

- カテゴリ・月のいずれも指定されていない場合はパンくず・見出しともになし、いずれか一方でも指定されていれば両方を出す。両方同時に指定された場合の見出し文言・パンくず表記は要判断（MVPでは「カテゴリと月は同時に絞り込めない」運用にするか、片方を優先表示するかを実装時に決める）
- キーワード検索（`keyword`）のみの絞り込みでは、パンくず・見出しともに出さない（要確認）
- ルーティングは変更しない。カテゴリ・月の絞り込みは引き続き`/`への`searchParams`（[5.5](#55-urlパラメータ)参照）で表現し、専用URL（例: `/categories/[slug]`）は作らない
- ページのh1は、絞り込み時のみこの見出し（`「◯◯」の記事一覧` ／ `◯年◯月の記事一覧`）が兼ねる。絞り込みなし時はページ内に視覚的なh1を置かない（要確認。アクセシビリティ上、視覚的に非表示のh1を用意する案もある）。キャッチコピー・パンくず自体はh1にしない

### 5.2 最新記事セクション

| 要素 | 仕様 |
|---|---|
| 見出し | 絞り込み時のみ表示する（太字）。`「◯◯」の記事一覧` ／ `◯年◯月の記事一覧`。絞り込みなし時は見出しテキストを表示しない。詳細は[5.1](#51-パンくずと見出しの切り替え)参照 |
| カテゴリ絞り込み | 一覧上部のタブは廃止し、サイドバーの「カテゴリー」（[5.4](#54-サイドバー)参照）のみで行う。月（ARCHIVE）の絞り込みと同じ構造になる |
| 記事カード一覧 | 縦積み。カード間は罫線で区切る。絞り込み条件と現在ページ・表示件数に該当する記事のみを表示する |
| 件数表示 | 一覧の右上（表示件数セレクトの左）に「◯件中 ◯〜◯件を表示」。絞り込み後の該当件数と、現在ページの表示範囲を示す |
| 表示件数セレクト | 件数表示の右にドロップダウン（`10件` / `20件` / `30件`、既定`10件`）。詳細は[5.2.1](#521-ページネーション)参照 |
| ページネーション | 一覧の下に「前へ」「ページ番号」「次へ」。詳細は[5.2.1](#521-ページネーション)参照 |
| 空状態 | 「該当する記事がありません」（件数表示・ページネーションは非表示） |

#### 5.2.1 ページネーション

モック（`margin-tech-notes`のページネーション確認用画面）に基づく仕様。

```
30件中 21〜30件を表示                         表示件数 [10件 ▾]

┌ 記事カード ───────────────────────┐
│ …（現在ページ分、最大10件）        │
└────────────────────────────────┘

              [ 前へ ]  [1] [2] [3]  [ 次へ ]
```

| 要素 | 仕様 |
|---|---|
| 件数表示 | `{絞り込み後の総件数}件中 {開始番号}〜{終了番号}件を表示`。総件数0件のときは表示しない |
| 表示件数セレクト | ラベル`表示件数`＋セレクトボックス。選択肢`10件` / `20件` / `30件`（既定`10件`）。変更すると1ページ目に戻る |
| ページ番号ボタン | 現在の総ページ数分を表示する（MVPでは省略記号なしの全件表示で可。ページ数が増えたら現在ページ周辺＋省略記号（`…`）方式への拡張を検討する） |
| 現在ページの表示 | 紺の塗り＋白文字の角丸ボタン。`aria-current="page"`を付与する |
| 前へ／次へ | 先頭ページで「前へ」、最終ページで「次へ」を無効化（`disabled`＋視覚的にグレーアウト） |
| ページ遷移時の挙動 | 一覧の先頭へスクロール。URLの`page`パラメータを更新する（[5.5](#55-urlパラメータ)参照） |
| 該当0件時 | ページネーションを表示せず、「該当する記事がありません」のみ表示 |

### 5.5 URLパラメータ

トップページの絞り込み・ページネーション状態はURLの`searchParams`に反映し、共有・ブックマーク・ブラウザの戻る操作に対応する。

| パラメータ | 例 | 用途 |
|---|---|---|
| `category` | `?category=TypeScript` | 選択中のカテゴリ（URLエンコード。例: `Next.js`） |
| `keyword` | `?keyword=hooks` | 検索キーワード |
| `month` | `?month=2026-09` | アーカイブの絞り込み |
| `page` | `?page=2` | 現在のページ番号（既定1） |
| `pageSize` | `?pageSize=20` | 表示件数（既定10） |

- カテゴリ・検索・月・表示件数のいずれかを変更したら`page`は1にリセットする
- サイドバーの`TOPICS`/`ARCHIVE`は、この`searchParams`を使ってトップページの該当状態へ直接ジャンプする（旧`/blogs`への遷移は廃止）
- 絞り込み・ページネーションの計算方法（クライアント側かサーバー側か）は[04_data_fetching_policy.md](../../frontend/docs/04_data_fetching_policy.md)の方針に従う。現状の記事数ではクライアント側（案A）で全件取得後にフィルタ・ページ分割すれば十分で、記事数が増えたらサーバー側（案B、`limit`/`offset`/`filters`）へ移行する

```
│ ───────────────────────────      │                    │
│ 本文…                            │                    │
└──────────────────────────────────┴────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| パンくず | 全幅の帯。`HOME`（青・リンク→`/`）＞ 記事タイトル（グレー・現在地）。トップページの絞り込み時・プロフィールと共通の部品（[3.3](#33-ヘッダー直下のパンくず)参照） |
| ヒーローサムネイル | 記事カードと同じ装飾サムネイルを大きく表示（角丸、約876×490） |
| メタ行 | `YYYY.MM.DD` ─ ラベル。ラベルはモックでは`SAMPLE ARTICLE`。本番では`ARTICLE`固定、またはカテゴリ名を出す（要判断） |
| タイトル | h1。太字・大きめ |
| カテゴリタグ | カードと同じ表現 |
| 要約 | グレーの大きめ本文 |
| 罫線 | 要約と本文の区切り |
| 本文 | microCMSのリッチエディタHTML。見出し・段落・リスト・コード・画像・引用にスタイルを当てる（`prose`相当のスタイルを用意）。HTMLは信頼できる自前CMS由来だが、描画前にサニタイズする（[07_api_design.md](./07_api_design.md)参照） |
| サイドバー | 検索・著者・カテゴリーに加え、**ARTICLES（最新の記事）**を数件表示。表示中の記事自身は除く |

- 前後の記事へのリンク、シェアボタン、関連記事は**MVP対象外**

## 7. このブログについて（`/about`）

- 見出し、コンセプト文、プロフィールページ（`/profile`）へのリンク。デザインは他ページのトーンに合わせる
- 文章は定数または`page.tsx`内に直接記述（CMS管理しない）

## 8. プロフィールページ（`/profile`）

別ブログの参考画像（パンくず＋タイトル＋メイン画像＋本文＋右サイドバー）の**構成**を取り入れ、見た目は本ブログ（MARGIN）のトーンで作る。参考画像の配色・枠線・ボタン形状はそのまま真似ない。

```
┌ ヘッダー（「プロフィール」がアクティブ） ────────────────────┐
│ HOME ＞ プロフィール                      ← パンくず帯（詳細ページと同じ）│
│ プロフィール                      │ [🔍 記事を検索]          │
│ ─────────────────────────      │ プロフィール（著者カード）  │
│ ┌────────────────────────┐    │ カテゴリー               │
│ │ メインビジュアル画像      │    │ ARCHIVE                  │
│ └────────────────────────┘    │                          │
│ 本文（見出し＋段落＋リスト）      │                          │
└─────────────────────────────────┴──────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| パンくず | `HOME`（リンク→`/`）＞ `プロフィール`。詳細ページ・トップページの絞り込み時と同じ部品を再利用する |
| ページタイトル | h1「プロフィール」＋下に罫線 |
| メイン画像 | 任意。角丸、横長（16:9または3:2）。未設定なら非表示 |
| 本文 | microCMSのリッチエディタHTML。「何をしている人か」「経歴」「スキル」などの見出し（h2）で区切る。h2は左に青いアクセントラインなど、MARGINのトーンで装飾する。記事詳細の本文スタイルを共用する |
| サイドバー | 検索・著者カード・TOPICS・ARCHIVE。**プロフィールページ上の著者カードは重複するため非表示にする案**もある（要判断） |
| シェアボタン | 参考画像にはあるが、**MVP対象外**（記事詳細のシェアと同じ扱い） |
| SNSアイコン | 著者カード内に表示（本文内には置かない） |

- 商談での提示先になるため、**経歴・使用技術・得意領域・連絡方法**を本文に載せる（掲載内容は運営者が決める）
- SEO: `generateMetadata`で`title`=「プロフィール」、`description`=著者の`bio`

## 9. レスポンシブ

| 幅 | レイアウト |
|---|---|
| PC（1024px以上） | 2カラム（メイン＋サイドバー） |
| タブレット（〜1023px） | 1カラム。サイドバーはメインの下に移動 |
| スマホ（〜639px） | 1カラム。記事カードはサムネイルを上、テキストを下に縦積み。ナビはコンパクト表示（ハンバーガー、または折り返し）。フィルタタブは横スクロール可 |

- ヘッダーのナビがスマホで収まらない場合の表示方法（ハンバーガー／折り返し）は実装時に決める

## 10. アクセシビリティ・SEO

- ナビは`<nav aria-label>`、現在ページに`aria-current="page"`
- カードのリンクはタイトルにアンカーを置き、カード全体をクリック可能にしても読み上げが重複しないようにする
- 装飾サムネイルは`aria-hidden`（情報はタイトル側にあるため）
- 色だけに頼らない（選択中フィルタは背景色＋`aria-pressed`）
- ページごとに`generateMetadata`で`title` / `description`（要約を利用）/ OGP を設定する
- 見出しは各ページでh1を1つにする（トップは絞り込み時のみ`「◯◯」の記事一覧`／`◯年◯月の記事一覧`。絞り込みなし時はh1なし。詳細は記事タイトル。[5.1](#51-パンくずと見出しの切り替え)参照）
